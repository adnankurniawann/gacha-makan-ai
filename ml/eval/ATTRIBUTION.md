# Atribusi data

`osm-cuisine.json` berisi nama, tag `cuisine`, dan tag `amenity` tempat makan
di Indonesia dari [OpenStreetMap](https://www.openstreetmap.org/copyright),
diambil lewat Overpass API oleh `scripts/snapshot-osm-cuisine.ts`.

© kontributor OpenStreetMap. Data tersedia di bawah
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Berkas ini adalah turunan dari basis data OSM, jadi ia juga berlisensi ODbL:
boleh dipakai dan dibagikan ulang dengan menyertakan atribusi ini, dan
turunannya harus dibagikan dengan lisensi yang sama. Lisensi kode proyek ini
tidak berlaku untuk berkas data tersebut.

Cache jawaban model di `cache/` dan hasil di `results.*` memuat nama-nama yang
sama, dan tunduk pada atribusi yang sama.
